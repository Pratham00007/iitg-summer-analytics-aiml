#  Dynamic Pricing Engine for Urban Parking Lots

> **Capstone Project – Summer Analytics 2025**  
> Organized by: *Consulting & Analytics Club × Pathway*

---

## 📌 Overview

Urban parking lots face inefficient usage due to fixed pricing. This project introduces a **real-time dynamic pricing engine** that adjusts prices based on **demand signals, vehicle types, traffic conditions, and competition**.

We simulate a real-time data pipeline and pricing logic inspired by **Pathway’s streaming architecture**, using only `pandas`, `numpy`, and `bokeh`.

---

##  Problem Solved

- Reduces **overcrowding** or **underutilization** by adjusting prices dynamically.
- Supports **vehicle rerouting** to nearby lots when full.
- Uses simple yet robust **ML-free modeling** (linear and rule-based).
